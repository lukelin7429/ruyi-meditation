# The Six Wondrous Dharma-Gates — Translation Notes

These notes record the main translation decisions for the Ru-Yi English translation of the *Liu miao famen* (六妙法門, Taishō T46, no. 1917 (Zhiyi)), so that its terms stay consistent across the whole text and with this site's other Tiantai translations.

## The text

- **Base text:** Taishō T1917, via the CBETA digital edition. Zhiyi died in 597; the text is in the public domain.
- **Other English translations:** we have not used any published translation; this translation is made directly from the Chinese.
- **Coverage check:** the Chinese text on each page was compared character by character with the CBETA source to make sure nothing was skipped.

## Terms

| Chinese | English | Notes |
|---|---|---|
| 數 / 隨 / 止 / 觀 / 還 / 淨 | counting / following / stilling / contemplating / returning / purity | The six wondrous gates. |
| 不定止觀 | the indeterminate calming-and-contemplation | One of Zhiyi's three kinds; this text's place in his system. |
| 修 / 證 | cultivation / realization | Each gate has both. |
| 止觀 | calming and contemplation | As in this site's Mohe Zhiguan. |
