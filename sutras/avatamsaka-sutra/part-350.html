Sharing One Essence with the Buddhas of All Time

The true-suchness similes reach one of their boldest claims yet: not merely that this dedication resembles suchness, but that it "shares one and the same essence with the buddhas of the three times." The comparisons that follow build toward a striking conclusion — this dedication of wholesome roots pervading every buddha-land in the ten directions, manifesting great spiritual power, and accomplishing true and complete enlightenment.

Translator: Ru-Yi Meditation Center Status: Part 350 — true-suchness similes continue Source: Taishō T279 (Śikṣānanda, Tang, 695–699 CE)

From Resemblance to Identity

Earlier similes claimed the dedication behaves like suchness — pervasive, unshaken, inexhaustible. Here the language shifts toward something stronger: it "shares one and the same essence with the buddhas of the three times," gathers in every worldly and transcendent dharma, and finally, in the last simile of this Part, itself accomplishes true and complete enlightenment — no longer merely resembling suchness, but acting with its full authority.

Chinese Source

譬如真如，一切法中，性常平等；善根迴向亦復如是，於諸世間修平等行。譬如真如，不離諸法；善根迴向亦復如是，盡未來際不捨世間。譬如真如，一切法中，畢竟無盡；善根迴向亦復如是，於諸眾生迴向無盡。譬如真如，與一切法無有相違；善根迴向亦復如是，不違三世一切佛法。譬如真如，普攝諸法；善根迴向亦復如是，盡攝一切眾生善根。譬如真如，與一切法同其體性；善根迴向亦復如是，與三世佛同一體性。譬如真如，與一切法不相捨離；善根迴向亦復如是，攝持一切世、出世法。譬如真如，無能映蔽；善根迴向亦復如是，一切世間無能映蔽。譬如真如，不可動搖；善根迴向亦復如是，一切魔業無能動搖。譬如真如，性無垢濁；善根迴向亦復如是，修菩薩行無有垢濁。譬如真如，無有變易；善根迴向亦復如是，愍念眾生，心無變易。譬如真如，不可窮盡；善根迴向亦復如是，非諸世法所能窮盡。譬如真如，性常覺悟；善根迴向亦復如是，普能覺悟一切諸法。譬如真如，不可失壞；善根迴向亦復如是，於諸眾生起勝志願，永不失壞。譬如真如，能大照明；善根迴向亦復如是，以大智光照諸世間。譬如真如，不可言說；善根迴向亦復如是，一切言語所不可說。譬如真如，持諸世間；善根迴向亦復如是，能持一切菩薩諸行。譬如真如，隨世言說；善根迴向亦復如是，隨順一切智慧言說。譬如真如，遍一切法；善根迴向亦復如是，遍於十方一切佛剎，現大神通，成等正覺。

Ru-Yi Translation

Just as true suchness, within every dharma, has a nature forever equal, so too is this dedication of wholesome roots: it cultivates equal practice throughout every world. Just as true suchness never leaves any dharma, so too is this dedication of wholesome roots: throughout every future age, it never abandons the world. Just as true suchness, within every dharma, is ultimately inexhaustible, so too is this dedication of wholesome roots: toward every sentient being, its dedication is inexhaustible. Just as true suchness contradicts no dharma at all, so too is this dedication of wholesome roots: it never contradicts the Dharma of the buddhas of the three times. Just as true suchness universally gathers in every dharma, so too is this dedication of wholesome roots: it entirely gathers in every sentient being's wholesome roots. Just as true suchness shares the same essence with every dharma, so too is this dedication of wholesome roots: it shares one and the same essence with the buddhas of the three times. Just as true suchness never separates from any dharma, so too is this dedication of wholesome roots: it gathers in and upholds every worldly and transcendent dharma. Just as true suchness cannot be eclipsed or obscured, so too is this dedication of wholesome roots: no world is able to eclipse or obscure it. Just as true suchness cannot be shaken, so too is this dedication of wholesome roots: no work of Māra is able to shake it. Just as true suchness's nature is free of any defiling turbidity, so too is this dedication of wholesome roots: cultivating the practice of a bodhisattva, it holds no defiling turbidity. Just as true suchness undergoes no change, so too is this dedication of wholesome roots: in its compassion for sentient beings, its mind undergoes no change. Just as true suchness cannot be exhausted, so too is this dedication of wholesome roots: no worldly dharma is able to exhaust it. Just as true suchness's nature is forever awakened, so too is this dedication of wholesome roots: it is universally able to awaken to every dharma. Just as true suchness cannot be lost or destroyed, so too is this dedication of wholesome roots: giving rise to a supreme resolve toward every sentient being, it is forever never lost or destroyed. Just as true suchness is able to illuminate greatly, so too is this dedication of wholesome roots: with the light of great wisdom, it illuminates every world. Just as true suchness cannot be put into words, so too is this dedication of wholesome roots: it is something no language at all can express. Just as true suchness upholds every world, so too is this dedication of wholesome roots: it is able to uphold every bodhisattva's own practice. Just as true suchness accords with worldly speech, so too is this dedication of wholesome roots: it accords with the speech of all wisdom. Just as true suchness pervades every dharma, so too is this dedication of wholesome roots: it pervades every buddha-land in the ten directions, manifesting great spiritual power, accomplishing true and complete enlightenment.

Reading note — Ru-Yi Meditation Center

The Part's closing simile marks a quiet escalation: earlier comparisons described the dedication as pervasive, illuminating, or inexhaustible — qualities suchness and the dedication share. This last one goes further, claiming the dedication itself "accomplishes true and complete enlightenment," collapsing the distance between the practice of dedicating merit and the goal that practice was always aimed toward.
