Path Giving Rise to the Buddha-Dharma, Ten Great-Being Names

Ten kinds of path giving rise to the buddha-dharma range from according with a good friend to the tathāgata's own seed itself; the ten names that follow then unpack the very word "bodhisattva" one syllable-group at a time, building outward from "bodhisattva" and "mahāsattva" through eight further being-names, each earned by a specific quality.

Translator: Ru-Yi Meditation Center Status: Part 750 — path giving rise to the buddha-dharma, great-being names Source: Taishō T279 (Śikṣānanda, Tang, 695–699 CE)

Ten Names Built From One Word

Every name in this list shares its second half — "sattva," being — and differs only in what precedes it: bodhi, mahā, foremost, excellent, unsurpassed, inconceivable. The list functions almost like an etymology lesson, showing that "bodhisattva" itself is simply the first of ten such names, no more privileged in form than "unequaled being" or "powerful being," each justified by its own stated reason.

Chinese Source

佛子！菩薩摩訶薩有十種出生佛法道。何等為十？所謂：隨順善友是出生佛法道，同種善根故；深心信解是出生佛法道，知佛自在故；發大誓願是出生佛法道，其心寬廣故；忍自善根是出生佛法道，知業不失故；一切劫修行無厭足是出生佛法道，盡未來際故；阿僧祇世界皆示現是出生佛法道，成熟眾生故；不斷菩薩行是出生佛法道，增長大悲故；無量心是出生佛法道，一念遍一切虛空界故；殊勝行是出生佛法道，本所修行無失壞故；如來種是出生佛法道，令一切眾生樂發菩提心，以一切善法資持故。是為十。若諸菩薩安住此法，則得大丈夫名號。

Ru-Yi Translation

"Son of the Buddha! A bodhisattva-mahāsattva has ten kinds of path giving rise to the buddha-dharma. What are these ten? Namely: according with a good friend is a path giving rise to the buddha-dharma, because it plants the same roots of goodness together with them; profound faith and understanding is a path giving rise to the buddha-dharma, because it knows the buddha's own sovereign freedom; giving rise to a great vow is a path giving rise to the buddha-dharma, because its mind is broad and expansive; patiently trusting one's own roots of goodness is a path giving rise to the buddha-dharma, because it knows that karma is never lost; cultivating practice throughout every kalpa without ever growing weary is a path giving rise to the buddha-dharma, because it reaches to the very limit of the future; manifesting throughout asaṃkhyeya worlds is a path giving rise to the buddha-dharma, because it brings sentient beings to maturity; never interrupting bodhisattva practice is a path giving rise to the buddha-dharma, because it causes great compassion to grow; a measureless mind is a path giving rise to the buddha-dharma, because within a single thought it pervades the whole realm of empty space; excellent practice is a path giving rise to the buddha-dharma, because the practice originally cultivated is never lost or damaged; and the tathāgata's own seed is a path giving rise to the buddha-dharma, because it causes every sentient being to delight in giving rise to the mind of awakening, sustaining it with every wholesome dharma. These are the ten. If bodhisattvas abide within this dharma, they attain the name of a great being.

Chinese Source

「佛子！菩薩摩訶薩有十種大丈夫名號。何等為十？所謂：名為：菩提薩埵，菩提智所生故；名為：摩訶薩埵，安住大乘故；名為：第一薩埵，證第一法故；名為：勝薩埵，覺悟勝法故；名為：最勝薩埵，智慧最勝故；名為：上薩埵，起上精進故；名為：無上薩埵，開示無上法故；名為：力薩埵，廣知十力故；名為：無等薩埵，世間無比故；名為：不思議薩埵，一念成佛故。是為十。若諸菩薩得此名號，則成就菩薩道。

Ru-Yi Translation

Son of the Buddha! A bodhisattva-mahāsattva has ten great-being names. What are these ten? Namely: named "bodhisattva," because they are born from the wisdom of awakening; named "mahāsattva," because they abide in the great vehicle; named "foremost being," because they realize the foremost dharma; named "excellent being," because they awaken to the excellent dharma; named "most excellent being," because their wisdom is most excellent; named "superior being," because they arouse superior diligence; named "unsurpassed being," because they reveal the unsurpassed dharma; named "powerful being," because they broadly know the ten powers; named "unequaled being," because they have no equal in the world; and named "inconceivable being," because they attain buddhahood within a single thought. These are the ten. If bodhisattvas attain these names, they accomplish the bodhisattva path.

Reading note — Ru-Yi Meditation Center

名為：菩提薩埵，菩提智所生故 — named "bodhisattva," because they are born from the wisdom of awakening. Setting "bodhisattva" as merely the first of ten parallel names, each formed the same way, treats the term not as a fixed title but as one instance of a pattern — a being named for whatever quality defines them, awakening being simply the first quality this list names.
