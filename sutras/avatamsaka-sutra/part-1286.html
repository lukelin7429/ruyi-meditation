Already Accomplished

Still before Maitreya, Good-Wealth asks directly how a bodhisattva learns the practices and cultivates the path — then names fifty things already true of anyone who has received a one-lifetime prediction to buddhahood.

Translator: Ru-Yi Meditation Center Status: Part 1286 — fascicle 78 begins Source: Taishō T279 (Śikṣānanda, Tang, 695–699 CE)

Already Accomplished

Fascicle seventy-eight opens with Good-Wealth's own question still addressed to Maitreya; fifty parallel clauses follow, each naming something already true the moment a bodhisattva receives a prediction to buddhahood in a single lifetime.

Chinese Source

爾時，善財童子合掌恭敬，重白彌勒菩薩摩訶薩言：「大聖！我已先發阿耨多羅三藐三菩提心，而我未知菩薩云何學菩薩行？云何修菩薩道？

Ru-Yi Translation

At that time, Good-Wealth, joining his palms in reverence, spoke once more to Maitreya Bodhisattva-Mahāsattva, saying: "Great sage! I have already aroused the mind of anuttara-samyak-sambodhi, but I do not yet know how a bodhisattva learns the bodhisattva practices, or how a bodhisattva cultivates the bodhisattva path?

Chinese Source

「大聖！一切如來授尊者記，一生當得阿耨多羅三藐三菩提；若一生當得無上菩提，則已超越一切菩薩所住處，則已出過一切菩薩離生位，則已圓滿一切波羅蜜，則已深入一切諸忍門，則已具足一切菩薩地，則已遊戲一切解脫門，則已成就一切三昧法，則已通達一切菩薩行，則已證得一切陀羅尼辯才，則已於一切菩薩自在中而得自在，則已積集一切菩薩助道法，則已遊戲智慧方便，則已出生大神通智，則已成就一切學處，則已圓滿一切妙行，則已滿足一切大願，則已領受一切佛所記，則已了知一切諸乘門，則已堪受一切如來所護念，則已能攝一切佛菩提，則已能持一切佛法藏，則已能持一切諸佛菩薩祕密藏，則已能於一切菩薩眾中為上首，則已能為破煩惱魔軍大勇將，則已能作出生死曠野大導師，

Ru-Yi Translation

Great sage! Every tathāgata bestows upon a venerable one a prediction that in a single lifetime they shall attain anuttara-samyak-sambodhi; if, in a single lifetime, one shall attain unsurpassed bodhi, then one has already transcended every dwelling-place of a bodhisattva; then one has already gone beyond every bodhisattva's own station of freedom from birth; then one has already fulfilled every pāramitā; then one has already deeply entered every gate of forbearance; then one has already become endowed with every bodhisattva ground; then one has already played freely within every gate of liberation; then one has already accomplished every dharma of samādhi; then one has already penetrated every bodhisattva practice; then one has already realized every dhāraṇī and eloquence; then one has already attained mastery within every bodhisattva's own mastery; then one has already gathered every dharma that aids a bodhisattva's own path; then one has already played freely within wisdom and skillful means; then one has already given rise to the wisdom of great spiritual penetration; then one has already accomplished every point of training; then one has already fulfilled every wondrous practice; then one has already satisfied every great vow; then one has already received every prediction given by a buddha; then one has already fully understood every gate of every vehicle; then one has already become fit to receive the mindful guarding of every tathāgata; then one is already able to gather every buddha's own bodhi; then one is already able to uphold every buddha's own dharma-treasury; then one is already able to uphold the secret treasury of every buddha and bodhisattva; then one is already able to be foremost within every assembly of bodhisattvas; then one is already able to become a great, courageous general who defeats the army of affliction's own māra; then one is already able to become a great guide who leads beings out of the wilderness of birth-and-death;

Chinese Source

則已能作治諸惑重病大醫王，則已能於一切眾生中為最勝，則已能於一切世主中得自在，則已能於一切聖人中最第一，則已能於一切聲聞、獨覺中最增上，則已能於生死海中為船師，則已能布調伏一切眾生網，則已能觀一切眾生根，則已能攝一切眾生界，則已能守護一切菩薩眾，則已能談議一切菩薩事，則已能往詣一切如來所，則已能住止一切如來會，則已能現身一切眾生前，則已能於一切世法無所染，則已能超越一切魔境界，則已能安住一切佛境界，則已能到一切菩薩無礙境，則已能精勤供養一切佛，則已與一切諸佛法同體性，已繫妙法繒，已受佛灌頂，已住一切智，已能普生一切佛法，已能速踐一切智位。

Ru-Yi Translation

then one is already able to become a great king of physicians who cures every grave sickness of delusion; then one is already able to be supreme among every sentient being; then one is already able to attain mastery among every lord of the world; then one is already able to be foremost among every noble one; then one is already able to be most exalted among every śrāvaka and pratyekabuddha; then one is already able to become a captain within the ocean of birth-and-death; then one is already able to spread a net that tames every sentient being; then one is already able to contemplate the faculties of every sentient being; then one is already able to gather in the realm of every sentient being; then one is already able to guard and protect every assembly of bodhisattvas; then one is already able to discuss every matter of a bodhisattva; then one is already able to travel to every place where a tathāgata dwells; then one is already able to abide within every assembly of a tathāgata; then one is already able to manifest one's own body before every sentient being; then one is already able to remain unstained by any worldly dharma; then one is already able to transcend every domain of māra; then one is already able to abide securely within every buddha's own realm; then one is already able to reach every bodhisattva's own unobstructed realm; then one is already able to diligently make offerings to every buddha; then one is already of the same essential nature as every buddha's own dharma; one has already bound on the silken sash of the wondrous dharma; one has already received a buddha's own consecration; one already abides in all-knowing wisdom; one is already able to universally give rise to every buddha-dharma; and one is already able to swiftly tread the station of all-knowing wisdom.

Reading note — Ru-Yi Meditation Center

則已超越一切菩薩所住處，則已出過一切菩薩離生位 — fifty parallel clauses, counted directly against the source text by splitting on every comma after the opening premise, all answering a single question: what does it mean that a one-lifetime prediction to buddhahood is already, in effect, every one of these fifty accomplishments at once? The grammar itself shifts partway through — 則已 ("then one has already") gives way to 則已能 ("then one is already able to") around the twentieth clause, and the final five clauses drop 則 entirely — all confirmed directly against the source rather than smoothed over in translation.
