# The Dharma Gate of Mahāyāna Calming-and-Contemplation — Translation Notes

These notes record the main translation decisions for the Ru-Yi English translation of the *Dasheng zhiguan famen* (大乘止觀法門, Taishō T46, no. 1924 (attributed to Huisi)), so that its terms stay consistent across the whole text and with this site's other Tiantai translations.

## The text

- **Base text:** Taishō T1924, via the CBETA digital edition (new punctuation, 2026 release). the work is attributed to Huisi (d. 577); the text is in the public domain.
- **Other English translations:** we have not used any published translation; this translation is made directly from the Chinese.
- **Coverage check:** the Chinese text on each page was compared character by character with the CBETA source to make sure nothing was skipped.

## Terms

| Chinese | English | Notes |
|---|---|---|
| 一心 / 如來藏 | the one mind / the tathāgatagarbha | The support of calming and contemplation. |
| 自性清淨心 | the mind pure in its own nature | The first name of the one mind. |
| 三性 | the three natures | The discriminated, the dependent, and the real (Paramārtha's names). |
| 性染 / 性淨 | inherent defilement / inherent purity | The mind contains both natures. |
