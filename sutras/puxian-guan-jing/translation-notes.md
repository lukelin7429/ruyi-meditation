# The Sūtra on Contemplating the Practice of Samantabhadra — Translation Notes

These notes record the main translation decisions for the Ru-Yi English translation of the *Guan Puxian pusa xingfa jing* (佛說觀普賢菩薩行法經, Taishō T9, no. 277 (tr. Dharmamitra)), so that its terms stay consistent across the whole text and with this site's other Tiantai translations.

## The text

- **Base text:** Taishō T0277, via the CBETA digital edition (new punctuation, 2026 release). The translation dates from the fifth century; the text is in the public domain.
- **Other English translations:** we have not used any published translation; this translation is made directly from the Chinese.
- **Coverage check:** the Chinese text on each page was compared character by character with the CBETA source to make sure nothing was skipped.

## Terms

| Chinese | English | Notes |
|---|---|---|
| 六根懺悔 | repentance of the six faculties | The sūtra's main practice. |
| 無相懺悔 | markless repentance | Recollecting the true mark. |
| 六牙白象 | the six-tusked white elephant | Samantabhadra's mount. |
