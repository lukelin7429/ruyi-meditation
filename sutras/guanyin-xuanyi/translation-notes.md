# The Profound Meaning of Guanyin — Translation Notes

These notes record the main translation decisions for the Ru-Yi English translation of the *Guanyin xuanyi* (觀音玄義, Taishō T34, no. 1726 (Zhiyi, recorded by Guanding)), so that its terms stay consistent across the whole text and with this site's other Tiantai translations.

## The text

- **Base text:** Taishō T1726, via the CBETA digital edition; in the public domain.
- **Attribution:** modern scholars have questioned how much of the text is Zhiyi's own; the traditional attribution is kept.
- **Other English translations:** we have not used any published translation; this translation is made directly from the Chinese.
- **Coverage check:** the Chinese text on each page was compared character by character with the CBETA source to make sure nothing was skipped.

## Terms

| Chinese | English | Notes |
|---|---|---|
| 性惡 / 修惡 | inherent evil / cultivated evil | The buddha cuts off cultivated evil but not inherent evil. |
| 普門 | the universal gate | Avalokiteśvara's way of responding everywhere. |
| 觀世音 | Avalokiteśvara, contemplating the sounds of the world | The name explained by its parts. |
| 十普 | the ten universals | Ten senses in which the gate is universal (Part 4). |
| 正因 / 緣因 / 了因 | the correct cause / the conditioning cause / the revealing cause | The three causes of buddha-nature, matched to this site's Fahua Xuanyi and Mahāparinirvāṇa Sūtra. |
