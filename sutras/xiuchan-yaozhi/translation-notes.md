# The Essential Purport of Repentance Practice — Translation Notes

These notes record the main translation decisions for the Ru-Yi English translation of the *Xiuchan yaozhi* (修懺要旨, Taishō T46, no. 1937, fascicle 2 (Zhili)), so that its terms stay consistent across the whole text and with this site's other Tiantai translations.

## The text

- **Base text:** Taishō T1937, fascicle 2, via the CBETA digital edition (new punctuation, 2026 release). Zhili died in 1028; the text is in the public domain.
- **Other English translations:** we have not used any published translation; this translation is made directly from the Chinese.
- **Coverage check:** the Chinese text on each page was compared character by character with the CBETA source to make sure nothing was skipped.

## Terms

| Chinese | English | Notes |
|---|---|---|
| 四種三昧 | the four samādhis | The frame in which Zhili places every repentance rite. |
| 理懺 | repentance in principle | Joined by Zhili to every act of the rite. |
| 圓常正信 | correct faith in the perfect and eternal | Where the practitioner must first set the mind. |
