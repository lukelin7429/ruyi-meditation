# The Gateway to the Sequence of the Dharma Realm — Translation Notes

These notes record the main translation decisions for the Ru-Yi English translation of the *Fajie cidi chumen* (法界次第初門, Taishō T46, no. 1925 (Zhiyi)), so that its terms stay consistent across the whole text and with this site's other Tiantai translations.

## The text

- **Base text:** Taishō T1925, via the CBETA digital edition (new punctuation, 2026 release). Zhiyi died in 597; the text is in the public domain.
- **Other English translations:** we have not used any published translation; this translation is made directly from the Chinese.
- **Coverage check:** the Chinese text on each page was compared character by character with the CBETA source to make sure nothing was skipped.

## Terms

| Chinese | English | Notes |
|---|---|---|
| 初門 | gateway | Each of the sixty categories is a gateway. |
| 三十七道品 | the thirty-seven factors of the path | Gateways 31–37. |
| 六波羅蜜 | the six pāramitās | Dāna, śīla, kṣānti, vīrya, dhyāna, and prajñā. |
| 十八不共法 | the eighteen unshared qualities | Gateway 55. |
