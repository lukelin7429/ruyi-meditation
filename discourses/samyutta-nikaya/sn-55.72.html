Why this discourse

Confirmed by direct comparison, “javanapaññā” (“swift wisdom”) is this discourse's own completion of the identical pair already met at SN 55.24 — there paired with “hāsapaññā” (SN 55.71's own term) as one of the qualities distinguishing an arahant, endowed with freedom.

Reading guide

Completing a pair from the Sarakāni controversy

This project's own direct cross-reference: SN 55.71 gave “hāsapaññā” its own dedicated discourse; this discourse now does the same for its own paired term, “javanapaññā” — together completing, across two separate discourses, the identical two-term phrase that at SN 55.24 described the arahant in a single breath.

Swiftness of insight, not physical speed

This project's own reading: “javana” (“swift, quick-moving”) shares its own root with the Abhidhamma's own technical term for the impulsion phase of cognitive process — a connection this project notes without overclaiming a direct citation in this discourse itself.

Key terms

javanapaññatāya saṁvattanti — “lead to swift wisdom” — this discourse's own specific result
javana — “swift, quick-moving” — a root this project notes is shared with the Abhidhamma's own technical term for cognitive impulsion, without overclaiming a direct citation here
… — the elision marking, standing in for the complete four-condition formula already given in full at SN 55.62
saddhammassavanaṁ — “listening to the true teaching” — the second condition, assumed here
Ekādasamaṁ — “the eleventh” — this discourse's own root text confirming its own position directly, read rather than assumed

The text

Every genuinely translated fragment given in the consulted English source, which itself preserves the elision back to SN 55.62. Translation: Bhikkhu Sujato (CC0, SuttaCentral).
